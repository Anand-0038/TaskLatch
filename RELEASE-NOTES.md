# Public-source release notes

This folder is a reviewable source snapshot for the Tameion submission. The project demonstration remains a self-use Arc Testnet run.

Included: project source, contract, tests, build configuration, MIT license, current screenshots, and the sanitized public operator-run view.

Intentionally omitted: the private `hack/` research and outreach files; `.env` and signer credentials; `.local/` runtime state; `node_modules/`, `dist/`, compiler output; the canonical run ledger containing provider signatures and raw fetched pages; and the copied third-party rules PDF. The snapshot is for source review and read-only UI inspection. The omitted owner-only run state and credentials mean the historical operator CLI cannot be replayed from this folder. Arc transaction links in the README are independently verifiable on the public testnet explorer.

The included 2:47 narrated MP4 is a historical self-use technical demo recorded on 27 September. It predates the latest TaskLatch UI and is not evidence of business traction. No new payment was made for this release.
